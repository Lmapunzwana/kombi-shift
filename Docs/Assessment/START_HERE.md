# Group 6 start here

This repository's current game is KombiShift2, Unity 6000.6.2f1. Morning Shift and Rush Hour share a city route but change time, delivery target and rival pressure. The menu is not a second level.

## Read and practise in this order

1. [Unity lessons](UNITY_LEARNING_PATH.md): open, navigate, inspect and trace the actual game.
2. [Current design](CURRENT_DESIGN.md): rules, target audience, storyboard, architecture and limitations.
3. [Learn and defend](LEARN_AND_DEFEND.md): questions each member must answer and live change practice.
4. [System diagrams](DIAGRAMS.md) and [code excerpts](CODE_EXCERPTS.md).
5. [Illustrated report](KombiShift2_Report.pdf) and [presentation](KombiShift2_Group6_Defence.pptx).
6. [Readiness](READINESS.md) and [testing procedure](TESTING_INSTRUCTIONS.md).

Each member should play both stages, trace a passenger from station to terminal, explain one rival decision, make and restore one small change, and record actual reviewed/modified work in CONTRIBUTIONS.csv. Suggested study areas do not establish authorship. The panel may question any member.

## Getting the update

Use branch `feat/kombishift2-unity6`, fetch/pull after saving your own work, and open the cloned repository folder itself in Unity Hub. It contains Assets, Packages and ProjectSettings. Do not add the parent workspace containing different prototype projects. If you have uncommitted edits, save/commit them before pulling; do not discard teammates' work to update.

The repository contains source, guides, report, presentation and selected evidence. The 1.2 GB HAI311_FinalProject_6.zip is a separate local submission review snapshot, not a Git file and not automatically updated by a pull. Builds and the submission ZIP are not uploaded by this change.
