# Three real tester sessions

Use the current release and write its SHA256/build ID in each row. Get consent and use anonymous T01/T02/T03 IDs. Do not post contact details. A facilitator observes without explaining every button; note where help was needed.

1. From title, ask the player to find instructions and explain the objective.
2. Select Morning; ask them to find a station, drive there, stop and board.
3. Ask what changed when passengers sat and what they must do next.
4. Ask them to follow the route to Mbare; record outcome/time/passengers and any confusion.
5. Pause, change volume, resume; then restart or return to menu.
6. Try Rush Hour; ask what changed and whether the competition feels fair.
7. Ask for the three most confusing/frustrating moments and one useful feature.

Record each task's observed result, not just a broad PASS. Severity: critical prevents start/completion; high blocks a core task; medium causes repeated confusion; low is a cosmetic/minor issue. Record hardware and ordinary-play frame data if available.

Select at least three genuine problems. In FEEDBACK_FIX_RETEST.csv link the actual observation to a fix/file/commit, then repeat the same task and record what the tester actually did. Do not count three arbitrary code edits as authentic feedback-based fixes. Return the completed CSVs to this chat for analysis and follow-up changes.
