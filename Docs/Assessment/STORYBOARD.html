Kombi Shift 2 storyboard

Current final-design storyboard, 8 November 2026. This is not backdated early-user research.

1 Title

Choose stage; see minutes and passenger target.

2 Learn

Read controls; boarding requires stopping below 2 km/h.

3 Approach

Minimap links the player, active station and rivals.

4 Board

Reserve queue; walk to separate seats; credit $2 each.

5 Deliver

Follow route; full cabin points to Mbare.

6 Result

Wait for delivered passengers; show success/failure and replay.

UI flow

Title → Instructions / Settings → Title → Morning or Rush Hour → Gameplay → Results → Replay / Menu.
Gameplay → Pause → Resume / Restart / Menu.
Morning success → Rush Hour.

Communication

Menu → Challenge → Director → Station → Passenger → Fare callback → Director → HUD / Result

The director owns rules and time. Stations own reservations. Passengers own movement and pose. Rivals use the same queue service. RCC handles vehicle physics.
